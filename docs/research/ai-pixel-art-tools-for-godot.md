## Practical recommendation

1. Start with **PixelLab** for actual production candidates: character sprites, directional variants, tilesets, and animation. Confirm the generated image dimensions, alpha channel, frame layout, and license for the chosen plan before importing into Godot.
2. Test **Retro Diffusion** beside PixelLab if a second dedicated pixel-art generator is useful, but obtain current pricing and output details from its product UI first because the public pages checked did not state them clearly.
3. Use **Scenario** when consistency, custom style training, API access, and batch generation matter more than a built-in pixel-art workflow.
4. Use **Leonardo** or **Krea** for concept exploration, image-to-image edits, background removal, and upscale. Neither should be treated as a native spritesheet or pixel-art solution based on the official claims checked here.
5. Use **Layer** only when the project benefits from a broader studio production system and usage-based workflow automation.

## Godot import notes

All six tools can be used in a normal offline asset workflow: download raster output, place it under the Godot project, then configure texture filtering to nearest and keep the source resolution/palette under version control. The research found no official claim among these six of a first-party Godot plugin or a Godot-specific export format. Godot therefore remains the place to assemble `Sprite2D`/`AnimatedSprite2D`, atlas regions, tile sets, collision, and import settings.

For animated output, do not assume that a “GIF,” “animation,” or “sprite sheet” claim gives Godot-ready frame layout. Check whether the tool exports separate PNG frames, a uniformly gridded atlas, or a video/GIF, and convert only if needed.

## Licensing cautions

- “Commercial use” is plan-dependent and can change. Scenario explicitly limits free outputs to personal/evaluation use; Krea's current pricing page says Free includes a commercial license but its terms should still be checked; Leonardo distinguishes paid ownership from free-tier licensing. Read the linked terms for the exact account and model before shipping.
- Platform-level commercial permission does not necessarily resolve rights in training references, trademarks, recognizable characters, or model-specific restrictions.
- Prices and allowances are snapshots checked on 2026-09-17, not guarantees. Credit/token systems make per-asset cost model-dependent.
