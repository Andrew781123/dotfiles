## How to Install Community Widgets

1. Find the widget in https://github.com/glanceapp/community-widgets/tree/main/widgets
2. Copy the YAML from the widget's `.yml` file
3. For simple widgets: paste directly into your `glance.yml` under the appropriate column's `widgets` array
4. For complex widgets: save to `glance/widgets/widget-name.yml` and reference with `$include`:

```yaml
widgets:
  - $include: widgets/immich-stats.yml
```

5. Set required environment variables (API keys, URLs, etc.) in your `.env` file or Docker environment
